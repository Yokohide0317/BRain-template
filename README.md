# BRain — Building Reliable AI Notes

**AIと育てる、あなたの知識と作業の記憶。**

BRain は、メモや仕事の記録を Markdown で整理し、AI と一緒に使うための空のテンプレートです。話題ごとに情報を分け、AI が見つけた学びは「候補」として残します。採用するかどうかは、あなたが決めます。Obsidian を使わなくても利用できます。

## こんなときに使えます

- 案件ごとの資料や決定を、後から探せるようにしたい。
- AI に過去の作業を参照させたいが、別の話題の情報は混ぜたくない。
- AI の提案を記録し、確かめてから次回の作業に生かしたい。

## まず使ってみる

1. このリポジトリをダウンロードし、フォルダを好きな場所に置きます。Obsidian を使う場合は、そのフォルダを保管庫として開きます。
2. [領域の例](Memory/scopes/index.md)を見て、自分の話題に合う領域を作ります。たとえば `example-project` のフォルダをコピーして `my-project` に改名します。`Memory/scopes/index.md` と `AGENTS.md` の領域一覧も更新してください。例の領域は、不要になったら削除できます。
3. AI ツールを使う場合は、このフォルダを作業場所として開き、最初の依頼で領域と対象を伝えます。AI を使わずに Markdown のメモ置き場として始めてもかまいません。

架空の依頼例:

> scope: my-project。`Projects/展示会準備.md` を新しく作り、展示会までの確認事項を整理して。決まっていないことは「未確認」と書いて。

`my-project` は自分で作った領域名に置き換えてください。実際の名前や資料を入れる前に、共有先を確認しましょう。

## フォルダの見方

```text
AGENTS.md                AI に最初に読んでほしい共通の入口
CLAUDE.md                Claude Code 用の入口
Memory/shared/           話題を問わず使う手順と記録書式
Memory/scopes/           話題ごとの記録と索引
  <領域名>/sources/       資料の所在
  <領域名>/knowledge/     確認した内容や学びの候補
  <領域名>/feedback/      訂正や振り返り
  <領域名>/rules/         提案中・承認済みの行動ルール
Projects/                案件ノートを置く場所
Templates/               メモ・案件・ルール候補の雛形
```

`example-project` と `example-learning` は、入れ物を示す架空の例です。実際のノートは入っていません。自分の領域を作るときは、例のフォルダ構成を参考にしてください。各領域の `index.md` から、その領域の記録をたどれます。

## 日々の使い方

1. 作業する領域を一つ決めます。AI に頼む場合は `scope: [領域名]` と対象ファイルを伝えます。
2. メモには日付と出典を残し、確認した事実と推測を分けます。[メモの雛形](Templates/note.md)と[案件の雛形](Templates/project.md)を使えます。
3. AI が得た学びは、その領域の `knowledge/` や `feedback/` に候補として記録します。それだけで次回からの指示にはなりません。
4. 繰り返し使う行動ルールは `rules/candidates.md` に提案します。文言と適用範囲をあなたが明示して承認した後、`rules/approved.md` に記録します。AI は自分で承認しません。

詳しい手順は[共通手順](Memory/shared/workflow.md)と[記録書式](Memory/shared/formats.md)にあります。別の領域の情報を使いたいときは、対象ファイルと転記先を明示してください。

## AI ツールとの接続

このフォルダのルートから AI ツールを起動し、使う領域と対象を伝えます。入口の扱いは製品ごとに異なります。

| ツール | このテンプレートの入口 | 確認すること |
| --- | --- | --- |
| [Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md) | `AGENTS.md` | 選んだ領域と対象を伝える |
| [Claude Code](https://code.claude.com/docs/en/memory) | `CLAUDE.md` から `AGENTS.md` を取り込む | 取り込んだ内容を確認する |
| [OpenCode](https://opencode.ai/docs/rules/) | `AGENTS.md` | 共通手順と書式も読むよう頼む |
| [Devin CLI](https://docs.devin.ai/cli/extensibility/rules) | `AGENTS.md` | 対象領域の索引まで読んだか確認する |

この表は各製品の文書に基づきます。この配布物で各 CLI の実行や、AI が指示に従うかどうかの試験はしていません。`AGENTS.md` に書かれた参照先を、すべてのツールが自動で読むわけではありません。

## 保存と共有で気をつけること

- このフォルダの文章による指示は、技術的なアクセス制限ではありません。厳密に情報を分けたい場合は、別の保管庫や OS の権限、AI 側の設定も使ってください。別アプリの自動記憶、会話履歴、MCP、クラウド上の Knowledge は、このテンプレートとは別に管理します。
- 同期や Git を使う前に、保存先・共有相手・送信されるファイルを確認してください。公開リポジトリに機密資料を入れないでください。Git では作業前に状態と差分を確認し、競合コピーは内容を照合してから整理します。自動 pull や push は設定していません。
- `.gitignore` は一部のローカル設定や一時ファイルを除外する補助です。過去に記録された内容は消せません。バックアップは同期とは別に用意してください。

## 配布について

設計上の参考: [agent-memory-vault](https://github.com/cindyxu1030/agent-memory-vault)。領域別の記録と候補の審査という考え方を参考にし、本文・コードは転用していません。このテンプレートにはライセンスを指定していません。公開や再配布の条件は配布者が決めて明記してください。
